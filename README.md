# CHJB Short Stays Ltd — Website

## Before deploying, update these in `src/App.jsx`:

1. **BOOKING_URL** — your Uplisting direct booking link
2. **WHATSAPP** — your WhatsApp number
3. **PHONE** / **EMAIL** — your contact details
4. **PROPERTIES** — your actual property names, descriptions, and image URLs

## Deploy to Vercel:

1. Push this folder to a GitHub repository
2. Go to [vercel.com](https://vercel.com) and sign in with GitHub
3. Click "Add New Project" → select this repo
4. Vercel auto-detects Vite — just click "Deploy"
5. Add your custom domain in Project Settings → Domains
